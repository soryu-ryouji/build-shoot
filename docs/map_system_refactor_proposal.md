# 无限地图与基地防守实施方案

- 状态：已确认并实施
- 数据格式：JSON `version: 2`
- 核心规则：无限地面、中心基地、JSON 固定巢穴、清场胜利、基地摧毁失败

## 1. 目标

- 地图不再具有固定矩形边界，格子坐标可向正负方向无限延伸。
- 基地位于 `[0, 0]`，怪物从巢穴生成并主动攻击基地。
- 炮塔、激光和炮弹均可攻击巢穴；巢穴摧毁后停止生成。
- 保留现有建筑、能源、升级、放置高亮和单一 JSON 地图管线。
- 不维护有限地图与无限地图两套玩法。

## 2. 无限地图实现

“无限”指坐标与内容地址不受固定尺寸限制，不代表创建无限节点。

- 格子尺寸固定为 64×64px。
- 格子坐标使用 `Vector2i`，基地位于 `[0, 0]`。
- `cell_to_world(cell) = Vector2(cell) * 64`。
- `world_to_cell(position)` 对世界坐标除以 64 后四舍五入。
- 地面根据镜头覆盖范围动态生成，并额外保留两格缓冲。
- 镜头远去的瓦片从 `TileMapLayer` 移除；建筑与巢穴的逻辑数据继续保留。
- 地面由地图 seed 和格子坐标确定，同一坐标始终得到同一瓦片。
- 建筑占用、基地占用和巢穴占用使用稀疏字典，不遍历无限地图。

## 3. 运行时结构

```text
Main
├── Arena / MapLoader
│   ├── GroundLayer       镜头附近的连续地面
│   └── DecorationLayer   确定性工业装饰
├── TileHighlights        可见格放置与局部范围高亮
├── Blocks                敌人集合、移动与索敌
├── BaseCore              基地生命与受击
├── Nest...               独立巢穴节点
├── Items                 玩家建筑
├── Balls                 炮弹
├── WorldCamera           局部无限镜头
└── HUD / UI              基地状态、商店、设置与结算
```

## 4. JSON 格式

```json
{
  "version": 2,
  "id": "industrial_01",
  "name": "中央防线",
  "tileset": "res://assets/tilesets/industrial.tres",
  "palette": {
    "floor_a": { "source": 0, "atlas": [0, 0] },
    "vent": { "source": 0, "atlas": [1, 1] }
  },
  "generation": {
    "seed": 41027,
    "ground_tiles": ["floor_a"]
  },
  "base": {
    "cell": [0, 0],
    "size": [3, 3],
    "hp": 1000
  },
  "nests": [
    {
      "cell": [-5, -4],
      "hp": 45,
      "spawn_interval": 7.0,
      "kind": "normal",
      "reward": 30
    }
  ]
}
```

| 字段 | 说明 |
| --- | --- |
| `version` | 当前为 2 |
| `palette` | 瓦片别名到 TileSet source/atlas 的映射 |
| `generation.seed` | 确定性地面种子 |
| `generation.ground_tiles` | 可用于无限地面的瓦片别名 |
| `base.cell` | 基地中心格 |
| `base.size` | 基地占用尺寸，当前 3×3 |
| `base.hp` | 基地生命 |
| `nests[].cell` | 巢穴格，不能与基地或其他巢穴重叠 |
| `nests[].hp` | 巢穴生命 |
| `nests[].spawn_interval` | 独立生成间隔，秒 |
| `nests[].kind` | normal、swift、armored、elite |
| `nests[].reward` | 摧毁金币奖励 |

加载器校验 JSON、TileSet、瓦片引用、基地尺寸和巢穴重叠。新增地图只需新增 JSON。

## 5. 镜头

- 开局对准基地。
- 空地拖动平移；WASD/方向键平移。
- 滚轮与双指缩放。
- Home 或 HUD“基”回到基地。
- 放置和朝向操作优先于镜头手势。
- 屏外巢穴由 HUD 绘制方向箭头。
- 相机移动时通知 MapLoader 更新可见瓦片。

## 6. 基地与敌人

- 准备期 5 秒，巢穴暂停生成、炮塔暂停开火。
- 每个巢穴独立计时，按 JSON 类型生成敌人。
- 敌人沿基地方向移动，不再向下滚动或离开固定底边。
- 敌人接触可拦截建筑时停下攻击；建筑摧毁后继续前进。
- 敌人接触基地后持续造成伤害。
- 基地生命归零后暂停游戏并显示失败结算。

## 7. 巢穴与攻击

- 巢穴是独立 Node2D，具有生命、生成计时、奖励和受击表现。
- 炮塔索敌将敌人与巢穴统一为目标字典，选择射程内最近目标。
- 激光通过统一 `hit_target` 分发敌人或巢穴伤害。
- 炮弹不再处理地图墙面，碰撞列表同时包含敌人与巢穴。
- 穿透、威力预算和压缩塔增益继续有效。
- 巢穴摧毁后从目标列表移除、停止生成、发放奖励并释放占用格。

## 8. 放置与范围

- 放置高亮只遍历镜头附近可建造格。
- 基地、现存巢穴和建筑占用格不可放置。
- 炮塔射程只遍历以自身为中心、半径覆盖的局部格子。
- 压缩塔范围限制为朝向两侧各 768 世界单位，显示与实际增益一致。
- 绿色表示可放置，红色表示非法，青色表示射程/施法范围。

## 9. 胜负

- `playing`：正常游戏。
- `won`：所有巢穴摧毁且敌人集合清空。
- `lost`：基地生命归零。
- 结算面板提供重开和返回主界面。

## 10. 验证

- 无限正负坐标与远距离坐标转换。
- 镜头移动后远处地面生成，返回后内容一致。
- 基地/巢穴不可建造，巢穴摧毁后释放格子。
- 炮塔与激光索敌巢穴，炮弹可摧毁巢穴。
- 巢穴独立生成，敌人向基地移动并攻击阵地。
- 基地失败与清场胜利结算。
- 第二无限 JSON 和重叠巢穴错误校验。
- 四种分辨率下的 HUD、商店、触摸放置和镜头坐标转换。
